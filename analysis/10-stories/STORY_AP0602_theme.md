# Dark and light theme

## User Story

As a developer using the workflow, I want a dark and a light theme toggle that persists locally, so that the portal matches my preference.

## Acceptance Criteria

- Given the toggle, when I switch theme, then all screens change.
- Given a reload, when it happens, then the choice persists in localStorage.
- Given both themes, when axe-core runs, then contrast passes WCAG 2.2 AA.
