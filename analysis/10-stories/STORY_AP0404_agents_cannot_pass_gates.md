# Agents cannot pass gates

## User Story

As a owner, I want gate endpoints to reject any call originating from an agent session, so that the hard boundary of AGENTS.md §3 holds.

## Acceptance Criteria

- Given a process launched by the run manager, when it calls a gate endpoint, then the call is rejected.
- Given the agent environment, when it is inspected, then it holds no portal token or nonce.
- Given the test suite, when it simulates an agent caller on every gate path, then all are rejected.
