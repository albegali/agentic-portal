# Launch workflow step

## User Story

As a developer using the workflow, I want to launch a step (kickoff, requirements, brief, run…) on a story or gate through an allow-listed agent CLI headless, claude -p or codex exec, so that I run the workflow without a terminal.

## Description

- Epic: EP-03 — Agent runs
- Priority (MoSCoW): Must · Release: R1 · Size: L · Type: feature
- Requirements: FR-07, FR-09, NFR-04
- Depends on: AP0102, AP0104, AP0201
- Notes: ADR-004: queue, scope locks, adapters. Streaming is AP0303. Agents never receive the portal token.
- Out of scope: Streaming UI, cancel.

## Acceptance Criteria

- Given a step whose preconditions hold, when I launch it, then the configured CLI starts with that step's command in the repo.
- Given preconditions fail (e.g. no approved RUN strategy), when I launch, then it is refused with the reason.
- Given project.toml tools switched from claude to codex, when I launch, then the launched command changes accordingly.
- Given a request naming a command not on the allow-list, when it reaches the API, then it is rejected.
