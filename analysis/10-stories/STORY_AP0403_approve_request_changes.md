# Approve and request changes

## User Story

As a developer using the workflow, I want approve and request-changes actions that write exactly what a human edit would, attributed to the project.toml owner with date, so that gates are explicit actions.

## Description

- Epic: EP-04 — Human gates
- Priority (MoSCoW): Must · Release: R1 · Size: L · Type: feature
- Requirements: FR-14, NFR-03, NFR-02
- Depends on: AP0102, AP0105, AP0402
- Notes: Writes go through gates.py (AP0105).
- Out of scope: Approving on behalf of other users.

## Acceptance Criteria

- Given a pending gate, when I confirm Approve, then only the gate field changes (e.g. status: approved) with owner and date recorded.
- Given a pending gate, when I request changes with a comment, then the comment is recorded and no approval is written.
- Given a gate action without the UI confirm nonce, when it is sent, then it is rejected.
