# Session streaming and run history

## User Story

As a developer using the workflow, I want live output of a running session and a history of runs with status, step, model, duration and trigger, so that I observe and audit runs.

## Description

- Epic: EP-03 — Agent runs
- Priority (MoSCoW): Must · Release: R1 · Size: L · Type: feature
- Requirements: FR-10, NFR-05, NFR-07, NFR-12
- Depends on: AP0301, AP0108
- Notes: Records in .portal/runs/ (ADR-008).
- Out of scope: Cancel, gates.

## Acceptance Criteria

- Given a running session, when it prints output, then the UI shows it live over SSE and a reload replays it.
- Given output containing a seeded secret pattern, when it is stored and streamed, then the secret is redacted in both.
- Given a finished run, when I open History, then step, model, start/end, outcome and who triggered it are listed.
- Given a fake CLI in tests, when it ends, then a run record exists for 100% of runs.
