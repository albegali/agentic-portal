# Tier model selection

## User Story

As a developer using the workflow, I want the model to come from the step's tier in models.toml for the configured vendor and be shown before launch, so that token discipline is respected.

## Acceptance Criteria

- Given a step of tier balanced, when the launch dialog opens, then the model from models.toml for the vendor is displayed.
- Given models.toml changed, when I open the dialog again, then the new model shows.
- Given a tier or vendor missing in models.toml, when I launch, then it is refused with a clear message.
