# Overview with next step

## User Story

As a developer using the workflow, I want to see lifecycle stage, next command, mode and tier on the overview, so that I know what to do without exploring files.

## Description

- Epic: EP-02 — Workflow state and navigation

## Acceptance Criteria

- Given a repository in a given state, when I open Overview, then stage, next command, mode and tier match `make next`.
- Given state changes on disk, when I reload, then the new state shows.
- Given the contract call fails, when I open Overview, then an error state with the reason is shown.
