# Backlog view

## User Story

As a developer using the workflow, I want to list epics and stories with status, filters and sorting, so that I have one backlog overview.

## Description

- Epic: EP-02 — Workflow state and navigation
- Priority (MoSCoW): Must · Release: R1 · Size: M · Type: feature

- Notes: —

## Acceptance Criteria

- Given backlog/stories.toml, when I open Backlog, then epics and stories show with counts equal to `make backlog`.
- Given the list, when I filter by epic, status or owner mode and sort, then only matching stories show.
- Given a story row, when I open it, then its detail opens.
