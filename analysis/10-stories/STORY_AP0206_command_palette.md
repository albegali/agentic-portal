# Command palette

## User Story

As a developer using the workflow, I want a keyboard palette to navigate screens, stories and actions, so that I work with console-like speed.

## Description

- Epic: EP-02 — Workflow state and navigation
- Priority (MoSCoW): Should · Release: R2 · Size: S · Type: feature
- Requirements: FR-06, NFR-11
- Depends on: AP0203
- Notes: Launch actions are added by EP-03 stories.
- Out of scope: Launching runs.

## Acceptance Criteria

- Given any screen, when I press the shortcut, then the palette opens and traps focus.
- Given the palette, when I type a story ID or screen name, then matching results show and Enter navigates.
- Given the palette, when I press Escape, then it closes and focus returns.
